# Durga_Puja_Dairy

**Global Durga Puja Discovery & Mandap Directory (Frontend Client)**  
Built with Next.js (App Router, Pure JavaScript), Tailwind CSS, and Lucide Icons.

---

## 🪔 Features
- **Place Selection System:** Interactive hierarchical country & district chips (Thakurgaon, Dhaka, Kolkata, London, New York, etc.).
- **Authentic Bengali Typography:** Powered by Google Font `Hind Siliguri` for beautiful native script rendering.
- **Festival Aesthetics & Motion:** Looping ambient visual hero banner, festival pulse animations, and responsive cards.
- **One-Click Navigation:** Direct Google Maps navigation links for every mandap.
- **My Diary:** Bookmark mandaps and plan personal Durga Puja Parikrama itineraries.
- **Community Submissions:** Unlisted mandap proposal wizard with duplicate checking.

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
